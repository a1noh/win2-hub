## 화면 구성 (탭 3개)

폰에서는 한 번에 한 섹션, 데스크톱에서는 넓게. **어디에 넣을지 고민할 필요가 없게** 3개로 단순화했습니다.

- **🏠 메인** — 다가오는 모든 일정이 한 피드에 (MT·모임·아웃팅·공지 전부, 가까운 순).
  각 항목에 `리더십`·`아웃팅`·`공지` 칩. 맨 위 **📌 고정** 영역은 상시 정보용(있을 때만).
- **📋 광고** — 이번 주 주일 광고 **슬라이드 사진** (탭하면 크게 보기). 날짜/구글 슬라이드 링크.
- **🗄️ 보관함** — 끝난 공지 전부 (최신순). 날짜가 지나면 **자동**으로 내려오고, 본문은 그대로 보관.

탭은 주소(`#gwanggo` 등)에 기억돼서 새로고침/뒤로가기 해도 유지됩니다.

## 기술

프레임워크·빌드·백엔드 없음. 순수 정적 사이트.

```
index.html          화면 뼈대
styles.css          스타일 (다크 모드 기본, 모바일 우선, 데스크톱 다단)
app.js              탭/렌더링/갤러리/라이트박스 (내용 수정 시 건드릴 필요 없음)
data.js             ← 내용은 전부 여기 (유일하게 고치는 파일)
images/             광고 슬라이드 (압축본) + images/thumbs/ (썸네일)
tools/compress_images.py   사진 압축 도구
UPDATING.md         업데이트 방법 (경우별)
```

- 내용은 `window.HUB_DATA` (JS 파일이라 `file://` 로 열어도 동작).
- 사진은 **lazy-load** — 📋 광고 탭을 열 때만 내려받아 첫 로딩이 빠릅니다.
- 날짜는 **America/New_York** 기준으로 "오늘"을 자동 계산 (`오늘`/`내일`/`D-6`/`진행 중`/`지남`).
- `<meta name="robots" content="noindex, nofollow">` — 멤버 이름이 있어 검색엔진 비노출
  (비밀은 아님, 링크를 아는 사람은 볼 수 있음).
- 외부 호출: 폰트(Pretendard CDN)뿐. 사진·스크립트는 모두 로컬. 애널리틱스·쿠키 없음.
